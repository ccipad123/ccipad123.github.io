陈辰 Chen Chen

直博生 · PhD Student
北京大学第一临床医学院

我目前在北京大学第一临床医学院攻读博士，导师为薛瑞栋研究员。主要从事空间转录组（Spatial Transcriptomics）算法设计，研究兴趣涉及计算病理学（Computational Pathology）与生物信息学（Bioinformatics）。

本科就读于北京林业大学数学与应用数学专业，研究主要围绕机器学习（Machine Learning）、模式识别（Pattern Recognition）与最优化理论（Optimization）展开。

我的研究聚焦于多视图学习（Multi-view Learning）领域，主要涉及支持向量机（Support Vector Machines）和安全筛选（Safe Screening），关注不同视图的共有信息与互补信息，以及数据结构、损失函数对分类模型的影响；相关工作也涉及非凸优化与工作集求解。论文发表于 Information Fusion、Expert Systems with Applications 等期刊。

# Corresponding author

Robust and sparse support vector machine via hybrid truncated loss for supervised classification

Yuliang Yang, Chen Chen, Yuxiang Liu, Huiru Wang#

Expert Systems with Applications 2027, 334: 134683 2025 JIF · 9.4

针对支持向量机中损失函数对异常样本敏感、非凸模型求解成本较高的问题，研究提出兼顾稀疏性与有界性的混合截断损失，构建单视图分类模型。通过 P-平稳点建立最优性条件，并结合工作集策略设计 ADMM 求解算法；进一步引入结构信息与视图权重，将模型扩展到多视图学习。合成、真实及图像数据集实验考察了分类性能、支持向量数量与噪声鲁棒性。

Multi-view support vector machine classifier via soft-margin loss with structural information

Chen Chen, Qianfei Liu, Renpeng Xu, Ying Zhang, Huiru Wang#, Qingmin Yu

Information Fusion 2025, 115: 102733 2025 JIF · 17.4

针对多视图分类中共有信息与互补信息难以同时利用的问题，研究提出基于 软间隔损失的两类支持向量机，并在结构化模型中引入数据结构信息。围绕离散损失带来的优化困难，建立最优解与 P-平稳点之间的理论联系，将工作集策略融入近端 ADMM。数值实验比较了分类性能、计算速度和支持向量数量，检验结构信息与求解策略的作用。

Multi-view structural twin support vector machine with the consensus and complementarity principles and its safe screening rules

Qianfei Liu, Chen Chen, Ting Huang, Yan Meng, Huiru Wang#

Expert Systems with Applications 2025, 265: 125814 2025 JIF · 9.4

通过聚类提取类内和类间结构，将其融入多视图孪生支持向量机：结构正则项保留视图间的一致性，视图权重用于利用互补信息，使模型兼顾类内紧凑性与类间可分性。研究采用迭代策略求解，并推导安全筛选规则，在不牺牲精度的前提下缩小优化问题规模、加快参数选择。数值实验同时考察了分类效果与筛选规则的安全性。

Deep multi-view least squares support vector machine with consistency and complementarity principle based on cross-output knowledge transfer

Shuangrui Jia, Sijie Liang, Ziyi Mo, Chunxiao Liu, Huiru Wang#, Chen Chen

Expert Systems with Applications 2026, 298: 129406 2025 JIF · 9.4

研究将多视图最小二乘支持向量机组织为深层堆叠结构，后续层利用前面各层的预测结果作为额外输入，通过跨输出知识迁移逐层学习。各层同时考虑一致性与互补性，并以交替优化策略求解；快速留一交叉验证用于评估层间迁移程度。模型允许对部分参数进行随机赋值，数值实验据此比较分类性能与计算效率。

Forest biomass carbon stock estimates via a novel approach: K-nearest neighbor-based weighted least squares multiple birth support vector regression coupled with whale optimization algorithm

Niannian Deng, Renpeng Xu, Ying Zhang, Haoting Wang, Chen Chen, Huiru Wang#

Computers and Electronics in Agriculture 2025, 232: 110020 2025 JIF · 10.3

森林生物量碳储量估计容易受到噪声和异常样本的干扰。研究提出最小二乘多生支持向量回归及其加权版本，用 K 近邻信息构造样本权重，使回归模型利用局部结构，并通过鲸鱼优化算法选择参数。在碳储量、模拟及 UCI 数据集上的比较，分别考察了预测精度、抗干扰能力与训练速度，分析加权策略和参数优化的效果。
